# Popover

Floating panel. Triggers on click.

## Import

```tsx
import {
  Popover,
  PopoverContent,
  PopoverTrigger,
} from "@ux/react"
```

## Example

```tsx
<Popover>
  <PopoverTrigger asChild><Button variant="outline">Open</Button></PopoverTrigger>
  <PopoverContent>Popover content goes here.</PopoverContent>
</Popover>
```
