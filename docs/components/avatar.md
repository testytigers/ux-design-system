# Avatar

User avatar with image and graceful fallback (initials).

## Import

```tsx
import {
  Avatar,
  AvatarFallback,
  AvatarImage,
} from "@ux/react"
```

## Example

```tsx
<Avatar>
  <AvatarImage src="https://github.com/shadcn.png" alt="@shadcn" />
  <AvatarFallback>SC</AvatarFallback>
</Avatar>
```
